# 中安智能大模型及智能应用平台介绍（厂商 PPT）

- **来源**：`raw/PPT/中安智能大模型及智能应用平台介绍.pptx`（36 页，北京中安智能信息科技有限公司「AI 专项产品介绍」）

## 公司画像

- 北京中安智能：2017-02 成立，国资领导下混合所有制（北京市国资牵头，占比 29.28%），定位「海洋智能系统供应商」，186 人。
- 资质：77 项发明专利 / 110 项软著；武器装备科研生产单位保密资格（二级）、装备承制资格、GJB 5000B 二级、CMMI5。

## 平台定位与架构

以大模型为核心引擎、**聚焦水下任务场景**的一体化平台，支撑「需求—设计—开发—部署—决策」闭环。四层架构：

| 层 | 内容 |
|---|---|
| 业务应用层 | 战场感知 / 导航通信 / 集群控制 / 红蓝对抗 |
| 智能服务层 | 水下 Agent / RAG 系统 / 低代码工作流 / 辅助开发工具 |
| 平台资源层 | 数据资源 / 模型资源 / 环境参数 / 作战想定数据 |
| 模型后台层 | 模型训练 / 部署 / 仓库 / 运行监控 |

## 四大核心能力 + 案例

1. **辅助开发工具**：原型设计→代码生成→代码移植→自动化测试闭环。案例：仿真模块 ROS2 移植岸基端（**7 天→0.5 天，10+ 倍**）、MATLAB 仿真程序移植 C++、接口测试文档→AI 生成用例→自动化测试报告。
2. **低代码工作流**：技术文档 / 方案稿 / 标书编制流程化（需求输入→知识检索→流程编排→输出发布）；AI 办公辅助（GB/T 9704-2012 公文模板 15+12 种）。
3. **RAG 系统**：以**水声教材 / 课程讲义 / 专业手册**为知识底座，术语抽取 + 图表公式索引 + 章节定位召回。
4. **决策 Agent**：意图理解 / 协同交互 / 方案生成 / 反馈修正；落地场景=区域探测 / 要道封锁 / 协同处置。

另有案例一「水面水下异构平台目标定位解算」：无人船消模糊机动轨迹 vs 镜像假设轨迹、目标位置后验分布与不确定度收敛可视化——与本工作区 USBL / 协同探测方向直接同域。

## 建设落地（内网离线部署）

- 组织：治理统筹—平台建设—知识运营—业务落地—安全运维五组分工。
- 保密：网络隔离（涉密专网、关外部 API）+ 数据分级 + 三维权限 + 输出管控（敏感词/水印/版本追踪）+ 审计追溯。
- **硬件**：2 台 8 卡昇腾 910B（16 NPU）本地推理；主力模型 GLM-5 系 / Qwen3.5-397B / DeepSeek-V4-Flash / Kimi-K2.5；代码推理 MiniMax-M2.5 / Qwen3-Coder-30B；检索 Qwen3-Embedding / BGE-M3。

## 与本工作区的关联

- 其「辅助开发 + RAG + 工作流 + Agent」四能力与本 Hub 的 Claude Code 体系（[[../agents/claude-codex-collaboration]]）同构，可作**内网国产化替代方案的对标参照**（昇腾 910B + 国产开源模型 vs 外网 Claude）。
- 水下任务场景（目标定位解算 / 区域探测 / 协同处置）与 [[../concepts/underwater-acoustic-communication]]、UWAcomm_usbl / CooperativeDetection 项目方向重叠——潜在竞对或合作方画像。
